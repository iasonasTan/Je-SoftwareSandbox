## Folders and sub-folders
```bash
   ~/Projects/Je-SoftwareSandbox ❯ tree -d -L 3
.
├── Apps
│   ├── Android # (All made in java)
│   │   ├── Irregular-Verbs-Quiz # Asks you for Irregular Verbs of the english language
│   │   ├── Linguistic-Links-Quiz # Asks you for the Categories of the greek linguistic links
│   │   └── Math-Helper-Quiz # Asks you for the result of simple mathematical operations
│   └── Desktop
│       ├── App-Server-Ascii-Art # Version checking server with a very nice ascii effect of the java logo (Made with java)
│       ├── Average-Calculator-Jfx # Counts the average value of the numbers that you enter (Made with Java and JavaFX)
│       ├── AverageCounter-DlangUI # Counts the average value of the numbers that you enter (Made with D and DlangUI)
│       ├── Library-Catalog-Jfx # Loads an xlsx file and helps you find a row (Started as a program to help people in libraries find books)
│       ├── Minecraft-Statistics-Viewer-Jfx # Shows you your minecraft stats based on the username you enter
│       ├── Notepad-NoLib # A TUI-Only notepad made with C.
│       ├── Physics-Simulator-Swing # Simulates objects with acceleration, speed and rules.
│       ├── TodoList-Swing # Simple GUI todo list app made with Java and JavaSwing/AWT.
│       └── WordFinder-Swing # GUI app that finds hidden words inside of a matrix.
├── Experiments
└── Games
    ├── Android # (All made with java)
    │   ├── Bricks-Breaker-NoLib # Bricks Breaking game made with Andriod API 'SurfaceView'
    │   ├── Rock-Paper-Scissors-NoLib # Rock Paper Scissors game with some extra features.
    │   └── Snake-LibGDX # Snake/Apple/Rocks game made with LibGDX for Android.
    └── Desktop
        ├── Console-Eater-NoLib # Pacman-Like game made with CPP (only TUI)
        └── Parkour-Game-jME # Simple parkour and chaser game (3D, jMonkeyEngine)
```

# Apps
Applications for desktop/andriod.
I call apps the programs that help with something important.

# Experiments
This folder contains experiments in different languages.
For example, it may contain OOP with C or Procedural programmin with Java.

# Games
This folder contains Games for android/desktop.
I call games the programs that have a game loop or doesn't help with something important.
