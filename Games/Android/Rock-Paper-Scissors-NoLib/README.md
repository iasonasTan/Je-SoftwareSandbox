# Rock Paper Scissors

A simple, local two-player Rock Paper Scissors Android application with a twist.

## Features

- **Local Multiplayer:** Play against a friend on the same device.
- **Vaptic Feedback:** Haptic feedback on every play.
- **Edge-to-Edge Design:** Modern Android look and feel.
- **Monochrome Icon Support:** Supports themed icons on Android 13+.
- **The "Rigged" Twist:** Secretly control the outcome using the system volume:
  - **Volume at 0:** Red always wins.
  - **Volume at 1:** Green always wins.
  - **Other Volumes:** Completely random.

## How to Play

1. Open the app.
2. One player takes the "Green" side (top, rotated), and the other takes the "Red" side (bottom).
3. Press the central Play button to reveal your moves.

## Secret Controls

Psst! If you want to impress (or frustrate) your friends, use the volume buttons:
- Set volume to **minimum (mute)** to ensure **Red** wins.
- Set volume to **level 1** to ensure **Green** wins.
- Keep it higher for a fair game.
